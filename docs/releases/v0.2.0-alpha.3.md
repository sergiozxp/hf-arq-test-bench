# HF-ARQ Modem Smoke 0.2.0-alpha.3

Pre-release of the two-PC smoke bench (profile MS-1.0, protocol v5.1). It checks
that each modem arm is installed, wired and controlled correctly. It is **not** a
performance measurement.

## Validated on real hardware (2026-10-22/23)

Two Windows PCs, one Behringer UCA222 each, direct audio cable (no channel
simulator), BW500, callsigns XQ2CG-1 / XQ2CG-2. Each arm ran E0-1 (16 B, 1 KiB,
10 KiB), E0-2 V1 and V2, and H1 ×3, and was cross-checked pair by pair:

| Arm | Pairs passed |
|---|---|
| Mercury 1.9.19 (official Windows ZIP) | 8 / 8 |
| VARA HF 4.9.0, unlicensed | 8 / 8 |
| VARA HF 4.9.0, licensed (`LINK REGISTERED`) | 8 / 8 |

## Scope

- Smoke test only, over a clean direct audio cable.
- What it shows: command interface, peer negotiation, framing, payload integrity
  (SHA-256 verified at the receiver and matched against the sender), evidence capture.
- Observed link levels and times are recorded but are not benchmark results.

## What is new

- VARA HF 4.9.0 adapter (licence state from VARA.ini; registration codes never stored).
- Full sequence: one RUN per PC runs the 8 tests in order.
- Strict session cross-check from the other PC's results ZIP.
- Mercury level meter; `LISTEN OFF` after every receiver run; procedure-fault outcome.
